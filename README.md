# Окно голодания

Трекер интервального голодания: подбор плана по опросу, таймер со стадиями и схемой процессов в организме, тренер, расписание, программа 21 день, рецепты, дневник ощущений, челленджи, питание с калориями и ссылкой на «Тарелку», вода, самочувствие, вес, норма калорий и белка, фото прогресса, замеры, ИМТ, сон, глюкоза и кетоны, учёт цикла, аналитика, календарь, достижения с картинками для друзей, отчёт за месяц, резервная копия. Работает офлайн, данные хранятся на устройстве.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (кнопка **New**), например `fasting-app`, тип **Public**.
2. На странице репозитория: **Add file → Upload files**, выберите все файлы из архива, нажмите **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты приложение откроется по адресу `https://ВАШ-ЛОГИН.github.io/fasting-app/`.

## Установка на телефон

- **iPhone (Safari):** откройте адрес → «Поделиться» → «На экран Домой».
- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение».

Приложение не заменяет консультацию врача.
